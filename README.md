# Depression Detection

![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-2.x-black?logo=flask&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green.svg)

A lightweight Flask app for depression detection and classification using NLP. Classifies user input text into depression severity levels.

> **Disclaimer:** For research purposes only. Not a substitute for professional mental health care.

## Getting Started

```bash
git clone https://github.com/Likash28/Depression_Detection.git
cd Depression_Detection
pip install -r requirements.txt
python app.py
```

## Tech Stack

- Python, Flask
- NLP / text classification
- HTML/CSS templates
